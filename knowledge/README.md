# `knowledge/` — durable `einring` knowledge

Evaluated, distilled knowledge that outlives a single task — plus this repository's decision records. Convention: `+wit/common/conventions/knowledge.md`.

| Path | Content |
|---|---|
| `decisions.md` | decision records of this repository (format: `+wit/common/conventions/decisions.md`) |
| `<category>/` | durable knowledge per category — the folder tree mirrors the repo's taxonomies in `structure/` and is created on demand only, never pre-generated |
