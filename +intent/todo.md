## Modular Components
The App shall contain management interfaces for many different Tools. 
- There must be an interface to enable and disable the modules.
- There must be an interface to individually configure the modules.
- Define a future framework for these modules
- In the future modules may not all be included in the main app but will be downloaded as individual packages. Check best practices for this behaviour and evaluate if this architecture should be implemented now or postpone it until required.
